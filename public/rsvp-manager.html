Как подключить Telegram-бота
  1. Напишите @BotFather в Telegram
  2. Отправьте команду /newbot и следуйте инструкциям
  3. Скопируйте полученный токен в поле "Telegram Bot Token" слева
  4. Узнайте свой Chat ID — напишите @userinfobot команду /start
  5. Вставьте Chat ID в соответствующее поле
  6. Напишите /start вашему боту — иначе он не сможет вам писать
  7. Сохраните настройки
Что умеет бот:
  • Уведомляет вас о каждом новом ответе гостя
  • Присылает напоминание о мероприятии со статистикой гостей
